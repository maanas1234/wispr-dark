## 1.0.0 - 2026-10-15

First release.

- One-click window to make Wispr Flow dark and to restore the original look.
- Single-file `Wispr-Dark.exe` for Windows. No Node.js or install needed.
- "Keep it dark after updates" option that re-applies the theme after Wispr updates itself.
- Command line: `apply`, `restore`, `status`, `auto on|off`, `ui`, `--version`.
- Original `app.asar` is backed up as `app.asar.orig` before any change.
